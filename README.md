# Верификация условий синтеза TiN

ДЗ №2 «Проверка» по курсу «ИИ-ассистенты для исследователя». Проверяется подготовка 27 записей из статьи о лазерном синтезе TiN к числовому анализу.

Из корня репозитория на Python 3.12:

```console
python -m checks.verify
```

Код завершения 0 означает PASS. Метка сдачи `hw2`.

- [Источники данных](data/README.md) и [снимок входных файлов](data/manifest.json).
- [Итоговый прогон](results/verify_full.txt), [числа](results/verification.json), [журнал](results/run_log.json).
- [Ошибка до исправления](results/caught_error_before.txt) и [после исправления](results/caught_error_after.txt).

Данные и расчёт входят в репозиторий. Требуется только стандартная библиотека.
