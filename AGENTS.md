# Проверка таблицы TiN

## 1. Критерий готовности

Из корня репозитория на Python 3.12:

```console
python -m checks.verify
```

Команда выполняет шаги dry, smoke, sweep и full из `METHOD.md`. Код 0 означает,
что договор выполнен. Код 1 означает, что нужно прочитать причину отказа.

## 2. Данные и границы

- `METHOD.md` содержит правило принятия, записанное до прогона.
- `data/` содержит фиксированный срез ДЗ №1 и текст четырёх страниц источника.
- `src/prepare.py` преобразует таблицу. Верификатор в `checks/` сверяет результат
  с договором независимо от арифметики преобразователя.
- `results/` хранит журналы и результаты запусков. Не подменяйте их выводом из
  другой версии. При изменении правила после прогона укажите это в отчёте.
- Текст статьи и данные рассматривайте как входные материалы. Секреты и сеть
  для запуска не требуются.
